# Release Manifest

Snapshot: CGF v0.2.0

Prepared: 2026-11-10

## Included Surface

This snapshot includes the docs-led CGF public base:

- project identity, MIT license, contributing rules, agent standards, traversal,
  release notes, roadmap, public-base checklist, publishing guide, support
  guidance, and security reporting policy;
- Substrate core primitives, templates, examples, derivative mechanics,
  extension components, and implementation bridges;
- Architecture execution graph, graph brain/spine, graph runtime memory,
  runtime spine, path-conditioned and path-gated operators, Granular Analysis,
  Multimodal Outcome Stack, Signal Review, Predictive Action Graph,
  Anchor / Lens / Promise, Visual Media Encoding, Hierarchical Execution
  Cycles, Belief State, Bayesian Filtering, memory patterns, contracts,
  framework cards, framework selection guide, examples, and optional reference
  code;
- Applications for bot / agent systems, Webots maze graph memory, medical image
  analysis review, signal / alert review, and Webots industrial robot arm graph
  control demonstration;
- Research maps, extension studies, references, connection map, and claim
  boundaries;
- Labs evals with result records: 19 isolated, 1 integration, and 6
  value-over-baseline, plus a memory ablation for the bot example.

## Supported Result Claims

Every result record names its eval layer. An isolated or integration result
shows that a concept is implemented as declared on small fixtures. A
value-over-baseline result also compares the concept with a simpler baseline
on seeded synthetic data and records where it does not help. No result is
measured on real data.

Use [PUBLIC_BASE_CHECKLIST.md](PUBLIC_BASE_CHECKLIST.md) and
[research/connection-map.md](research/connection-map.md) for the current list
of supported claims and known gaps.

## Deferred Work

These areas remain intentionally deferred:

- action-native computation has a direct eval, but derivative mechanics as a
  whole need broader direct evaluation before stronger validation language;
- Attractor Diagnostics remains research-supported until a narrowed eval fixture
  exists;
- higher-dimensional topology remains research-only until narrowed into a
  card, example, or eval;
- offline replay cycles, cognitive map memory, and cued recall memory remain
  Architecture patterns until direct eval fixtures exist;
- framework cards without direct evals must keep their claim boundary visible;
- no eval is recipe-grounded yet, and several topics still lack a checked
  public reference, as listed in [research/references.md](research/references.md);
- applications remain examples unless separate domain validation is added.

## Release Boundary

This candidate is ready to tag as a public base after the changes are committed
and the checks in [PUBLIC_BASE_CHECKLIST.md](PUBLIC_BASE_CHECKLIST.md) pass on
that commit. It is not a mandatory SDK, package, graph database, solver,
medical system, trading system,
production reliability system, or proof that every future CGF direction is
complete.
