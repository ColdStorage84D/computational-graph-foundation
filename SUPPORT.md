# Support

CGF is a public, documentation-led foundation rather than a supported product
or hosted service.

Use public repository discussions or issues for:

- questions about choosing a Substrate or Architecture path;
- reproducible documentation defects and broken links;
- failures in checked-in tests or examples;
- focused proposals that preserve the project boundaries in
  [CONTRIBUTING.md](CONTRIBUTING.md).

Include the commit or release identifier, operating system, Python version,
command, and complete error output when reporting a runnable failure.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities or
sensitive data. Do not use public issues for production emergencies, medical
advice, robot safety decisions, or claims beyond the documented example scope.
