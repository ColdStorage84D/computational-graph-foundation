# Labs

Labs hold active prototypes, experiments, negative results, and unfinished
ideas.

Labs are allowed to be messy. Anything promoted out of Labs needs:

- a cleanup pass;
- a maturity label;
- a clear parent section;
- no dependency on private data;
- no contradiction with Substrate or Architecture boundaries.

Current Labs maps:

- [evals/README.md](evals/README.md): runnable CGF-local eval code, fixtures,
  and reviewed result summaries.
- [evaluation-backlog/README.md](evaluation-backlog/README.md): pending eval
  specs for topics that do not yet have CGF-local code.

Cross-layer map:

- [../FOUNDATION_TRAVERSAL.md](../FOUNDATION_TRAVERSAL.md): project-wide path
  for selecting CGF pieces and reading claim strength.
- [../research/connection-map.md](../research/connection-map.md): shows which
  Substrate cards, Architecture concepts, and Research studies each Labs eval
  supports.
