# Evaluation Backlog

This folder records evaluation specs that CGF should implement later.

It is not a result record. A page in this folder means the concept needs a
CGF-local, reproducible eval before any result claim can be made.

## Backlog Rule

Do not use pass-status labels unless this repo contains the eval code,
fixtures, expected behavior, and a reviewed result.

Until then, use:

```text
pending-cgf-eval
```

## Current Pending Evals

No pending eval specs are currently listed here.

Implemented evals live in [../evals/README.md](../evals/README.md).

## Page Format

Each page should state:

- status;
- failure mode to test;
- minimum eval shape;
- draft acceptance criteria;
- claim boundary.

The page should not summarize unverified pass results.
