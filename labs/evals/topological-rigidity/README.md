# Topological Rigidity Eval

Status: `contract-pass`

This eval tests a derivative topology-preservation contract on tiny geometric
fixtures:

- exact unit-carrier validation;
- dimension-independent Gram-area and normalized non-collinearity diagnostics;
- area and angular retention relative to a declared nondegenerate reference;
- sampled integer degree for an explicit nonvanishing $U(1)$ phase;
- a closed-area cycle score explicitly labeled as non-invariant;
- collapse risk composed from compression and reference-relative deficit;
- evidence-only output with no physical-theory authority.

The evidence record names the closed-area cycle output `n_data` and the
sampled explicit-phase degree `m_data`. These names are local derivative
diagnostics, not physical flux, charge, or stability claims.

It does not treat a generic unit vector or polygon area as integer winding. It
does not validate persistent homology, learned topology preservation, or any
microscopic physical theory.
