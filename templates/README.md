# Templates

Templates are copyable working documents for applying CGF.

Use root templates when the task crosses multiple CGF layers. Use Substrate
templates when the task is only to declare a graph-shaped computational subject.

## Available Templates

- [project-intake.md](project-intake.md): project-level traversal record for
  choosing a CGF mix, tracing support, and identifying implementation gaps.

## Rule

Templates are not schemas, APIs, or SDK contracts. They are readable Markdown
records that help developers and agents make decisions without guessing.
