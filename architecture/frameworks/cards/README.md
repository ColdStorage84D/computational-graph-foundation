# Framework Cards

Framework cards describe reusable Architecture patterns.

Each card uses this shape:

```text
Purpose
Reusable concept
Uses CGF pieces
Example applications
When to use
When not to use
Boundary
Implementation posture
```

Cards are intentionally compact. Application examples can show richer domain
details, but the reusable concept should remain here.
