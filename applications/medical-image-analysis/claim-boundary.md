# Medical Image Analysis Claim Boundary

This page defines what the medical image analysis application can claim in CGF.

## Current Claim

The medical image analysis application currently claims only this:

```text
CGF can describe a medical image analysis review workflow as a composition of
reusable Architecture framework concepts.
```

The synthetic example can show:

```text
source evidence separation
bounded decoded records
typed multimodal graph shape
multi-lens proposal flow
review decision instead of automatic authority
trace preservation
training-only label exclusion
```

The browser fixture demo can show:

```text
local fixture images
case selection
visible lens outputs
competing proposals
verifier decision
rejected alternatives
trace inspection
```

Optional benchmark-resource testing can show only this:

```text
locally supplied benchmark records can run through the same CGF pipeline
```

## Not Claimed

The medical image analysis application does not claim:

- diagnosis authority;
- clinical safety;
- regulatory readiness;
- medical-device behavior;
- provider workflow validation;
- patient outcome benefit;
- model performance;
- benchmark performance;
- dataset representativeness;
- replacement of professional judgment;
- replacement of source systems;
- correctness of any medical finding.

## Promotion Requirements

Any stronger medical image analysis claim requires domain-specific work outside
the generic CGF framework claim:

```text
domain problem statement
source evidence governance
dataset and cohort description
reviewer role and authority
ground truth or adjudication process
safety policy
failure-mode analysis
model or processor validation
human factors review, when relevant
deployment boundary
external legal / regulatory review, when relevant
```

Until then, medical image analysis remains an application example and a useful
pressure test for CGF separation rules.
