# Extension Cards

Extension cards describe optional Substrate components.

Cards are intentionally concise. Deeper theory, validation discussion, and
research status live in
[../../../research/extension-studies/README.md](../../../research/extension-studies/README.md).
For card-to-study-to-eval links, use
[../registry.md](../registry.md) or
[../../../research/connection-map.md](../../../research/connection-map.md).

Each card uses the same format:

```text
Definition
Parent layer
Problem solved
Minimum substrate shape
When to use
When not to use
Maturity
```
