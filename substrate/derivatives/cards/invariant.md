# Invariant

## Definition

Invariant declares a quantity, relation, or admissibility condition that should
remain stable across evolution or transformation.

## Question it answers

What must stay true while the subject changes?

## Depends on core primitives

State, action, constraint, evolution, readout, validation.

## Minimum declaration

- Quantity or relation that should remain stable.
- Scope where it applies.
- Allowed tolerance, if any.
- Evolution steps or transformations it must survive.
- Validation check.

## When to use

- A conserved or protected quantity matters.
- A readout is invalid if a relation changes.
- Evolution should preserve a domain condition.

## Common failure

A subject claims stable behavior but never declares what stability means or how
to check it.
