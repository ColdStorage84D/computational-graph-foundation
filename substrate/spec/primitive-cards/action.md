# Action

## One Sentence

Action declares the cost, law, objective, risk, preference, or rule of behavior
that governs the subject.

## Question It Answers

What behavior is preferred, minimized, preserved, explained, or optimized?

## Required Status

Core. Required for every Substrate subject.

## Minimum Declaration

- Behavior being preferred or minimized.
- Field values involved.
- Graph parts involved.
- Direction of preference.
- Domain meaning.

## Allowed Examples

- Neighboring temperatures should become smoother.
- Lower-cost valid assignments are preferred.
- Suspicious activity should receive higher risk.
- A checkout path should create a valid order.

## Validation Questions

- Is preferred behavior stated explicitly?
- Can the action be evaluated from declared state?
- Is the action separate from readout?
- Are competing preferences named clearly?

## Common Mistakes

- Running state changes without naming what they serve.
- Treating a score as meaningful without declaring what it means.
- Mixing unrelated preferences without naming their relationship.
- Hiding business meaning in implementation details.
