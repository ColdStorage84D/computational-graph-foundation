# Primitive Cards

Primitive cards are quick-reference pages for the 9 core Substrate primitives.
They are shorter than the full guide and more practical than the concept page.

Each card uses the same format:

```text
One Sentence
Question It Answers
Required Status
Minimum Declaration
Allowed Examples
Validation Questions
Common Mistakes
Heat Example
Related Core Primitives
```

For the full teaching guide, read [../../primitives.md](../../primitives.md).
For the formal contract, read [../00-overview.md](../00-overview.md).
